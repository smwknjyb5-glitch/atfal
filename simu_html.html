تعلّم HTML خطوة بخطوة

من الصفر حتى الاحتراف — خمسة مستويات تفاعلية
🟢 المستوى الأول: مبتدئ
أساسيات لغة HTML: هيكل الصفحة، العناوين، الفقرات، الروابط، الصور، والقوائم. هذا المستوى يبني عندك القاعدة التي يقوم عليها كل شيء لاحقًا.

1. هيكل صفحة HTML الأساسي

▾

كل صفحة HTML تبدأ بإعلان النوع <!DOCTYPE html>، ثم وسم <html> الذي يحتوي على <head> (معلومات الصفحة غير الظاهرة) و<body> (المحتوى الظاهر للمستخدم).

<!DOCTYPE html>
<html lang="ar">
<head>
  <title>صفحتي الأولى</title>
</head>
<body>
  <h1>مرحبًا بالعالم</h1>
</body>
</html>

2. العناوين والفقرات

▾

وسوم العناوين من <h1> إلى <h6> ترتب المحتوى من الأهم إلى الأقل أهمية. أما <p> فتُستخدم للفقرات النصية العادية.

<h1>عنوان رئيسي</h1>
<h2>عنوان فرعي</h2>
<p>هذا نص فقرة عادية يشرح فكرة معينة.</p>
🧪 جرّب بنفسك:

3. الروابط والصور

▾

الرابط يُنشأ بوسم <a href="...">، والصورة بوسم <img src="..." alt="...">. الصورة وسم مفرد لا يحتاج إغلاقًا.

<a href="https://example.com">زيارة الموقع</a>
<img src="photo.jpg" alt="وصف الصورة">
🧪 جرّب بنفسك:

4. القوائم

▾

القائمة غير المرقّمة <ul> والمرقّمة <ol> تحتويان على عناصر <li>.

<ul>
  <li>عنصر أول</li>
  <li>عنصر ثانٍ</li>
</ul>
🧪 جرّب بنفسك:
🔵 المستوى الثاني: متوسط
الآن ستتعلم تنظيم المحتوى بشكل أعمق: الجداول، الحاويات div وspan، النماذج، والوسوم الدلالية في HTML5.

1. الجداول

▾

الجدول يُبنى من <table> يحتوي صفوف <tr>، وكل صف يحتوي خلايا <td> أو رؤوس <th>.

<table border="1">
  <tr><th>الاسم</th><th>العمر</th></tr>
  <tr><td>نجيب</td><td>20</td></tr>
</table>
🧪 جرّب بنفسك:

2. div و span

▾

<div> حاوية عامة على مستوى الكتلة (تبدأ سطرًا جديدًا)، بينما <span> حاوية داخل السطر تُستخدم لتنسيق جزء صغير من النص.

<div>
  هذا نص داخل <span style="color:red">كلمة مميزة</span>
</div>
🧪 جرّب بنفسك:

3. النماذج (Forms)

▾

وسم <form> يحتوي حقول إدخال مثل <input> و<button> لجمع بيانات من المستخدم.

<form>
  <input type="text" placeholder="اسمك">
  <button>إرسال</button>
</form>
🧪 جرّب بنفسك:

4. الوسوم الدلالية في HTML5

▾

وسوم مثل <header> و<nav> و<main> و<footer> تعطي معنى واضحًا لأجزاء الصفحة بدل الاعتماد الكامل على div.

<header><h1>موقعي</h1></header>
<main>المحتوى الرئيسي</main>
<footer>جميع الحقوق محفوظة</footer>
🧪 جرّب بنفسك:
🟡 المستوى الثالث: حسن
تبدأ هنا بدمج التنسيق البصري: الأصناف والمعرّفات، الوسائط المتعددة، والإطارات المضمّنة.

1. class و id

▾

class يُستخدم لتصنيف عناصر متعددة بنفس التنسيق، بينما id يُستخدم لعنصر واحد فريد في الصفحة.

<style>
  .box{color:gold;} #main{font-weight:bold;}
</style>
<p class="box" id="main">نص منسّق</p>
🧪 جرّب بنفسك:

2. الصوت والفيديو

▾

وسوم <audio> و<video> تسمح بتضمين الوسائط مباشرة مع خاصية controls لإظهار أدوات التحكم.

<video controls width="200">
  <source src="clip.mp4" type="video/mp4">
</video>

ملاحظة: المثال أعلاه يحتاج ملف فيديو حقيقي ليعمل، لذلك لا يوجد معاينة مباشرة له هنا.

3. iframe (تضمين صفحة داخل أخرى)

▾

<iframe> يسمح بعرض صفحة ويب أخرى داخل صفحتك، ويُستخدم كثيرًا لتضمين خرائط أو فيديوهات يوتيوب.

<iframe src="https://example.com" width="300" height="150"></iframe>

4. سمات (Attributes) متقدمة على العناصر

▾

مثل title لإظهار تلميح عند التحويم، وtarget="_blank" لفتح الرابط في نافذة جديدة، وdata-* لتخزين بيانات مخصصة.

<a href="#" target="_blank" title="افتح في نافذة جديدة">رابط</a>
🧪 جرّب بنفسك:
🟠 المستوى الرابع: جيد جدًا
في هذا المستوى تتعلم الأمور التي تجعل صفحتك احترافية وجاهزة للنشر: النماذج المتقدمة، الوصولية، الميتاداتا، والتجاوب مع الشاشات.

1. أنواع مدخلات النماذج المتقدمة

▾

مثل email، number، date، checkbox، وradio، مع خاصية required للتحقق من الإدخال.

<input type="email" required placeholder="بريدك الإلكتروني">
<input type="date">
<input type="checkbox"> أوافق
🧪 جرّب بنفسك:

2. الوصولية (Accessibility)

▾

استخدام alt للصور، وlabel المرتبط بحقل الإدخال عبر for، يجعل الصفحة قابلة للاستخدام من قارئات الشاشة لذوي الإعاقة البصرية.

<label for="name">الاسم:</label>
<input id="name" type="text">
🧪 جرّب بنفسك:

3. الميتاداتا و SEO

▾

داخل <head>، وسوم <meta> تصف الصفحة لمحركات البحث ومنصات التواصل، مثل الوصف والكلمات المفتاحية.

<meta name="description" content="وصف موجز للصفحة">
<meta name="viewport" content="width=device-width, initial-scale=1">

4. التصميم المتجاوب (Responsive)

▾

وسم viewport ضروري ليتكيف التصميم مع شاشات الجوال، وغالبًا يُستكمل بـ CSS media queries.

<meta name="viewport" content="width=device-width, initial-scale=1.0">
<style>
  @media (max-width:600px){ body{font-size:14px;} }
</style>
🟣 المستوى الخامس: ممتاز
أنت الآن تتقن HTML بمستوى احترافي: الرسم بـ Canvas، تخزين البيانات، القوالب الدلالية الكاملة، والتكامل مع جافاسكربت.

1. عنصر Canvas للرسم

▾

<canvas> مساحة رسم يتم التحكم بها عبر JavaScript لرسم أشكال، رسوم متحركة، أو ألعاب — وهو ما تعتمد عليه أغلب مشاريعك التفاعلية.

<canvas id="c" width="200" height="100"></canvas>
<script>
  const ctx = document.getElementById('c').getContext('2d');
  ctx.fillStyle = 'gold';
  ctx.fillRect(20,20,100,50);
</script>
🧪 جرّب بنفسك:

2. التخزين المحلي (localStorage)

▾

يسمح لصفحتك بحفظ بيانات في متصفح المستخدم تبقى بعد إغلاق الصفحة، مفيد لحفظ إعدادات أو تقدّم مستخدم.

localStorage.setItem('name', 'نجيب');
const name = localStorage.getItem('name');

3. الوسوم الدلالية الكاملة + ARIA

▾

دمج <article>، <section>، <aside> مع خصائص aria-* يرفع جودة الصفحة من ناحية البنية والوصولية معًا، وهو معيار مواقع الاحتراف.

<section aria-label="التعليقات">
  <article>تعليق المستخدم هنا</article>
</section>

4. دمج HTML مع Web APIs

▾

في هذا المستوى تربط HTML بواجهات برمجية متقدمة مثل Geolocation أو Web Audio API أو Speech Synthesis — وهي بالضبط ما استخدمته في مشاريعك (مواقيت الصلاة، محاكاة الوجه الصوتية).

navigator.geolocation.getCurrentPosition(pos => {
  console.log(pos.coords.latitude, pos.coords.longitude);
});
